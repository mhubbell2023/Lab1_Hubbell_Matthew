## Overview

TaskSquirrel is an iOS app that allows users to create and complete tasks by attaching photos. When a photo is attached to a task, the app uses the photo's location data to display where the photo was taken on a map.

## Features

- View a list of tasks
- Create new tasks
- Attach a photo to complete a task
- Access photo location metadata
- Display the photo location using MapKit
- Display the attached photo as a custom map annotation
- View the attached photo on a separate screen
